# C++ Primer 交互读本

> 由 `md/` 中的分章 Markdown 驱动的阅读器。
> 左侧按章 / 节导航，右侧直接渲染 PDF 转换出的原文；代码块可高亮、一键复制、载入工作台并在线编译运行。

基于《C++ Primer（中文版）第 5 版》的内容，将 PDF 转换为分章 Markdown 后，本机读取并渲染。
整套体验完全在浏览器端完成：目录、章节导航、Markdown 渲染、C++ 语法高亮、代码复制、在线编译、代码工作台、阅读偏好持久化。

## 功能特性

- 章节来自 `md/manifest.json`；每章打开后从 Markdown 的 `##` / `###` 标题自动生成二级目录。
- 滚动时高亮当前小节；点部分名（如「第Ⅰ部分 C++ 基础」）可跳到该部分导言。
- 若某章对应的 `md` 文件不存在（HTTP 404），该一级菜单置灰并禁用点击。
- 启动时若记录的章节缺失，自动退到下一个存在的章节。
- **正文**：Markdown 渲染（标题、段落、列表、引用、代码、图片、表格），不含页码等版式标记；
  每章开头的纸质目录已移除，改用左侧章节导航。
  文中的「2.5.2 节」这类引用会自动变成链接：本章小节直接滚动定位，其它章的小节先切换到对应章再定位。
- **代码**：C++ 语法高亮、一键复制；带 `main` 的完整程序可「载入编辑器 / ▶ 运行」，
  经 Wandbox 在线编译，支持切换编译器与 C++ 标准。
- **工作台**：可拖动、缩放，行号、Tab 缩进、`Ctrl+Enter` 运行、stdin 输入。
- **本地头文件**：工作台运行代码时，会从 `md/headfiles/` 查找并展开 `#include "文件名.h"`；
  标准库形式的 `#include <...>` 仍由云端编译器处理。
- **阅读辅助**：章节进度、字号（15–21px）、明暗主题、全屏；偏好写入 `localStorage`。
- **位置记忆**：自动记住上次阅读的章节与滚动位置（按章节保存锚点），下次打开直接回到原处。
- 页面不再包含原创课程或练习题，内容完全来自 `md/*.md`。

## 快速开始

```powershell
# 1) 安装测试依赖
npm install

# 2) 运行测试
npm test

# 3) 启动本地静态服务器
python -m http.server 8080
```

打开 `http://localhost:8080/`。若没有 `md/`，页面会显示「还没有本地原文」的提示。

## 目录结构

```
index.html            页面骨架
reader.js             md 驱动的阅读器（目录、正文、工作台、Wandbox）
md.js                 Markdown 渲染器（UMD，页面与测试共用）
highlight.js          C++ 语法高亮（UMD）
code-blocks.js        「完整可编译程序」判定（UMD）
style.css             全部样式
tools/test_*.js       渲染、高亮、可运行判定、jsdom 冒烟测试
md/                   本地转换结果（git 忽略）
node_modules/         测试依赖（npm install 生成，git 忽略）
```

## 测试

```powershell
npm install
npm test
```

覆盖 Markdown 渲染与转义、C++ 高亮、可运行程序判定，以及 jsdom 下的目录、章节切换、
代码块增强、工作台运行与阅读偏好。
